# KeenKeeper 🤝

> Your personal tool for meaningful connections. Discover, bond, and nurture the relationships that matter most.

## 🛠️ Technologies Used

- **React.js** — UI framework
- **React Router DOM** — Client-side routing
- **Recharts** — Analytics pie chart
- **Lucide React** — Icons
- **Vite** — Build tool

## ✨ Key Features

1. **Friend Dashboard** — View all your friends in a 4-column grid with status indicators (On Track / Almost Due / Overdue)
2. **Quick Check-In** — Log a Call, Text, or Video interaction from the Friend Details page — automatically adds to the Timeline
3. **Friendship Analytics** — Pie chart breakdown of your interaction types (Call / Text / Video / Meetup)

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 📄 Pages

- `/` — Home / Dashboard
- `/friend/:id` — Friend Detail page
- `/timeline` — Interaction timeline
- `/stats` — Friendship analytics
